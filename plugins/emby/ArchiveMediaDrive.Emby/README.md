# Emby adapter implementation package

Use the Emby plugin-with-UI template and Channel file-browser sample as prior art. Implement a native Channel and an optional plugin-managed standard-library mount using the shared .NET core. The project is pinned to `MediaBrowser.Server.Core` 4.9.1.90 on `netstandard2.0`, with acceptance against Emby Server 4.9.3.0 and 4.10.0.11-beta.
